# Ảnh kiểm tra bố cục giao diện

Các ảnh tạo từ bản publish Release bằng tùy chọn `--ui-check`.
Màn hình dùng phiên giả chỉ dành cho kiểm tra bố cục và các record minh họa; không kết nối CSDL hoặc chứng minh thao tác bán hàng.
Ba hộp thoại được kiểm tra thêm bằng cách nhập dữ liệu và bấm Lưu vào callback giả.
Kết quả kiểm tra SQL thật nằm trong `../nhu-integration.txt`, đối chiếu demo ở `../nhu-sql-reconciliation.txt`.

Ảnh 07–09 là các trang chủ tiệm; 10–12 là các trang nhân viên, không có nút quản lý.
Ảnh 13–15 là hộp thoại loại bánh, sản phẩm, nhập lô; ảnh 16 là tab chi tiết lô.
Ảnh 01–06 kiểm tra các màn hình Accounts/Customers có sẵn sau thay đổi menu chung.
